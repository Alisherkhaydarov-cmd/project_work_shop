# Отчёт по дипломной работе

## 1. Тема
Разработка интернет-магазина на фреймворке Django.

## 2. Цель
Создать веб-приложение, позволяющее пользователю просматривать каталог товаров, регистрироваться, работать с корзиной и избранным, искать товары и оставлять отзывы.

## 3. Использованные технологии
- Python
- Django 6.1.1
- SQLite
- HTML
- CSS
- Pillow

## 4. Основные модели
- Category — категория товара;
- Product — товар;
- Review — отзыв пользователя;
- Cart и CartItem — корзина;
- Order и OrderItem — заказ;
- Favorite — избранный товар.

## 5. Реализованная функциональность
Регистрация и вход, каталог, категории, поиск, карточка товара, корзина, оформление заказа, избранное, отзывы, административная панель и работа с изображениями.
