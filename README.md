# Дипломный проект — Интернет-магазин на Django

Проект выполнен на простом уровне: обычные Django views, forms, templates, SQLite и стандартная система аутентификации.

## Возможности
- регистрация и вход;
- каталог и категории;
- поиск по названию;
- карточка товара;
- корзина: добавление, изменение количества, удаление;
- оформление заказа;
- избранное;
- отзывы и рейтинг;
- административная панель для товаров, категорий, отзывов, корзин и заказов;
- изображения товаров через Django Media.

## Установка

1. Установить Python.
2. Открыть папку проекта в PyCharm.
3. Создать виртуальное окружение:

```bash
python -m venv venv
```

4. Активировать окружение и установить зависимости:

```bash
pip install -r requirements.txt
```

5. Выполнить миграции:

```bash
python manage.py migrate
```

6. Создать администратора:

```bash
python manage.py createsuperuser
```

7. Запустить проект:

```bash
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/

Админка: http://127.0.0.1:8000/admin/

## Заполнение

Сначала в админке создай несколько категорий и товаров. Для товара можно загрузить изображение. После этого зарегистрируй обычного пользователя и проверь каталог, корзину, избранное и отзывы.

## Важно

Django 6.1.1 — актуальный официальный bugfix-релиз на момент подготовки проекта. Для реального продакшена нужно заменить `SECRET_KEY`, отключить `DEBUG` и настроить `ALLOWED_HOSTS`.
